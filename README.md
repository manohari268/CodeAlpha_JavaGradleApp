# CodeAlpha Java Gradle Application

## Overview

This project is developed as part of the **CodeAlpha DevOps Internship**. It demonstrates how to build and execute a Java application using **Gradle**, a powerful build automation tool.

The application simulates a simple DevOps build report by displaying project information, build status, features, and a CI/CD pipeline workflow.

---

## Technologies Used

* Java 17
* Gradle 8.8
* Gradle Wrapper
* Git
* GitHub

---

## Features

* Java application built using Gradle
* Build automation using Gradle Wrapper
* Displays project details
* Simulates a DevOps build report
* Demonstrates CI/CD pipeline workflow
* Easy to build and execute
